# Dime US Portfolio Tracker (PWA)

แอปติดตามพอร์ตหุ้นสหรัฐฯ ที่ถือผ่าน Dime ออกแบบสำหรับ iPhone (ติดตั้งผ่าน “เพิ่มไปยังหน้าจอโฮม”)

**Live:** https://yongwiit.github.io/Dime/

## สถานะสถาปัตยกรรม (ปัจจุบัน)

| ส่วน | สิ่งที่ใช้ตอนนี้ | หมายเหตุ |
|---|---|---|
| Frontend | React 18 + Vite + TypeScript | Mobile-first, ธีมมืด/สว่าง, ฟอนต์ IBM Plex Sans Thai |
| PWA | vite-plugin-pwa (manifest + service worker) | ใช้งานออฟไลน์ได้หลังเปิดครั้งแรก |
| Hosting | GitHub Pages ผ่าน GitHub Actions | Deploy อัตโนมัติทุกครั้งที่ push `main` (รันเทสต์ก่อน) |
| ฐานข้อมูล | IndexedDB ในเครื่อง (ต่อเบราว์เซอร์/อุปกรณ์) | ไม่มีเซิร์ฟเวอร์ ข้อมูลไม่ออกจากเครื่อง; สำรอง/กู้คืนด้วยไฟล์ JSON |
| Login | **ยังไม่มี** | ต้องมีบัญชี Supabase (ดูหัวข้อ “งานที่เหลือ”) |
| ผู้ช่วย | แบบกฎ (rule-based) คำนวณจากข้อมูลพอร์ตจริง | **ไม่ใช่ LLM**; การบันทึกจากแชทต้องกดยืนยันเสมอ |
| ข้อมูลตลาด | อัตราแลกเปลี่ยน: Frankfurter (ECB) • ราคา/ข้อมูลวิจัย: Finnhub (ใส่ key ฟรีของผู้ใช้เอง) | แสดงแหล่งที่มาและเวลาข้อมูลทุกครั้ง |

ไม่มี Dime API ทางการที่เปิดให้บุคคลทั่วไปเชื่อมต่อ แอปจึงใช้การกรอกเอง การยืนยันคำสั่งรอดำเนินการ และการนำเข้า CSV แอปไม่ขอรหัสผ่าน Dime และไม่ส่งคำสั่งซื้อขายใดๆ

วิธีคำนวณบัญชีอยู่ใน [ACCOUNTING.md](ACCOUNTING.md)

## วิธีติดตั้งบน iPhone
1. เปิด **Safari** ไปที่ https://yongwiit.github.io/Dime/
2. กดปุ่ม **แชร์** (สี่เหลี่ยมมีลูกศรขึ้น) → **เพิ่มไปยังหน้าจอโฮม** → **เพิ่ม**
3. เปิดแอป “Dime Port” จากหน้าจอโฮม (ควรใช้จากไอคอนนี้เสมอ เพื่อให้ข้อมูลอยู่ที่เดียวกัน)

## ข้อควรรู้เรื่องที่เก็บข้อมูลบน iPhone
- iOS แยกที่เก็บข้อมูลของ **Safari**, **แอปบนหน้าจอโฮม** และ**เบราว์เซอร์ในแอปอื่น** (เช่น เปิดลิงก์จาก LINE) ออกจากกัน ข้อมูลที่กรอกในที่หนึ่งจะไม่ปรากฏในอีกที่
- ให้ใช้งานจากไอคอนบนหน้าจอโฮมเป็นหลัก หากต้องการย้ายข้อมูล: สำรอง JSON จากที่เดิม → กู้คืนในที่ใหม่
- ฐานข้อมูล: IndexedDB ชื่อ `keyval-store`, object store `keyval`, key `dime-portfolio-v1`, schema v1 (ดูได้ในหน้า ตั้งค่า → ข้อมูลระบบ)
- ถ้าอ่านข้อมูลเดิมไม่ได้ หรือข้อมูลหายไปจากที่เคยบันทึก แอปจะแจ้งเตือนและ**ไม่เขียนทับ**จนกว่าผู้ใช้จะเลือกเอง

## วิธีใช้งานเบื้องต้น
- **เริ่มต้น**: กด “นำเข้ายอดหุ้นที่ถืออยู่” แล้วกรอกจำนวนหุ้น ต้นทุนรวม และ FX จริงจาก Dime ถ้าหุ้นตัวนั้นมีคำสั่งรอดำเนินการ ต้องเลือกเองว่าเป็นคำสั่งเดียวกันที่สำเร็จแล้ว หรือเป็นการซื้อแยก (ระบบไม่เปลี่ยนคำสั่งรอเป็นสำเร็จเอง)
- **ภาพรวม**: มูลค่าพอร์ต (THB/USD), กำไร/ขาดทุน, เงินสด, สถานะคำสั่ง (ถือจริง / รอดำเนินการ / ยกเลิก), สัดส่วน, กราฟ
- **รายการ**: เพิ่ม/แก้ไข/ลบ รายการ; คำสั่งรอดำเนินการ → กด “ยืนยันว่าสำเร็จ” แล้วกรอกจำนวนหุ้น ราคา และอัตราแลกเปลี่ยนจริงจาก Dime
- **หุ้นที่ถือ**: แตะหุ้นเพื่อตั้งชื่อ กลุ่มอุตสาหกรรม ระยะยาว/เทรด เป้าหมายสัดส่วน และราคาปัจจุบัน (กรอกเอง)
- **ผู้ช่วย**: ถามคำถามเกี่ยวกับพอร์ต หรือพิมพ์ “ซื้อ NVDA จำนวน 1 หุ้น ราคา 180 USD อัตรา 33.4” → ตรวจตัวอย่าง → กด **ยืนยันบันทึก**
- **เพิ่มเติม**: วิจัย (ต้องมี Finnhub key), รายงานรายเดือน/ปันผล, ส่งออก CSV, **สำรอง/กู้คืน JSON**, ตั้งค่าอัตราแลกเปลี่ยนและเกณฑ์ความเสี่ยง

Finnhub key ไม่ถูกรวมในไฟล์สำรอง แต่ไฟล์สำรองมีข้อมูลพอร์ตทั้งหมด จึงไม่ควรส่งให้ผู้อื่น

ข้อมูลเก็บอยู่ในเครื่องเท่านั้น หากลบแอปหรือล้างข้อมูล Safari ข้อมูลจะหาย — **กด “สำรองข้อมูล (JSON)” แล้วเก็บไว้ใน iCloud Drive เป็นประจำ**

## งานที่เหลือ (ต้องได้รับอนุญาตจากเจ้าของ)
1. **Login + ฐานข้อมูลคลาวด์ (Supabase)** — สร้างโปรเจกต์ Supabase (ฟรี) แล้วให้ Project URL และ anon key; ต้องอนุญาตโดเมน `*.supabase.co` ใน Claude (Settings → Capabilities) จึงจะตั้งค่าตารางและ RLS ให้ได้
2. **ผู้ช่วย AI แบบ LLM** — ต้องมี API key ของผู้ให้บริการ AI ซึ่งต้องเก็บไว้ฝั่งเซิร์ฟเวอร์ (เช่น Supabase Edge Function) ห้ามใส่ในแอปฝั่งเบราว์เซอร์
3. **อินดิเคเตอร์ทางเทคนิค / correlation** — ต้องมีแหล่งราคาย้อนหลังที่อนุญาต (แผนฟรีของ Finnhub ไม่มีข้อมูลแท่งเทียน)

## นำเข้าจากภาพ Dime (OCR ในเครื่อง)
- ปุ่ม **นำเข้าจากภาพ Dime** (หน้าแรก, หุ้นที่ถือ, รายการ) → เลือกหรือถ่ายภาพหน้าจอ Dime: รายการ → ลงทุน → หุ้นสหรัฐฯ ส่วน “เสร็จสิ้น”
- อ่านภาพในเครื่องด้วย Tesseract.js (ฟรี ไม่มี API key ภาพไม่ถูกส่งออกจากเครื่อง) ไฟล์ตัวอ่าน ~11 MB โหลดครั้งแรกที่ใช้ แล้วเก็บไว้ใช้ออฟไลน์
- อ่านเฉพาะรายการใต้หัวข้อ “เสร็จสิ้น” ค่าที่ไม่แน่ใจจะถูกไฮไลต์และต้องแก้หรือยืนยันก่อน ไม่มีการบันทึกจนกว่าจะกด **ยืนยันและนำเข้า**
- โค้ด: `src/ocr/` • เทสต์: `tests/ocr/ocr.test.ts` (OCR จริงกับภาพจำลองทั้งหมดใน `tests/fixtures/` สร้างด้วย `make-fixtures.py` — ข้อมูลสมมติ), `tests/e2e/screenshot.e2e.mjs`
- **ห้ามใส่ภาพหน้าจอจริงลงใน Repo** (Repo นี้เป็นสาธารณะ)
- การทดสอบบน iPhone จริงที่ยังต้องทำ: [docs/REAL_DEVICE_ACCEPTANCE.md](docs/REAL_DEVICE_ACCEPTANCE.md)
